## 下一次接手

1. 双击根目录 `OpenProject.cmd`。启动关卡是 `/Game/Game/Maps/L_InteractionLab`，在内容浏览器中对应 `Content/Game/Maps/L_InteractionLab`。
2. 点击「运行」，再点击游戏画面。`WASD` 滚动，鼠标绕球观察，`R` 回到起点，`Esc` 退出试玩，`Shift+F1` 释放鼠标。
3. 退出试玩后，打开 `Content/Game/Player/BP_RollingBall`。在「类默认值」的 `Tuning` 中，把 `LookSensitivity` 从 `0.5` 改为 `0.35`，编译后再运行，比较观察速度。
4. 在下面的日志里写一句自己的选择：哪种观察速度合适，为什么。然后我们从这个版本进入沾染实验。

不要按旧聊天中的 BallPuzzle、RainGarden 或 Bouquet 路径继续制作。当前地图里的球和格子地面来自引擎基础形状、模板材质，只用于验证操作。

## 蓝图从哪里看

| 资产或函数 | 负责什么 | 你要修改时从哪里开始 |
| --- | --- | --- |
| `Game/Core/BP_ExplorationMode` | 指定默认玩家球 | 类默认值的 Default Pawn Class |
| `Game/Player/BP_RollingBall` 的 EventGraph | 出生初始化和每帧调用顺序 | BeginPlay 与 Tick 事件 |
| `UpdateCamera` | 鼠标改变视角，俯仰限制 -70 到 -10 度 | LookSensitivity、俯仰 Clamp |
| `RollInput` | WASD 按相机水平朝向滚动 | RollAcceleration、MaxSpeed、方向归一化 |
| `ResetBall` | 清空速度、传送回出生点 | 保存的 SpawnTransform 和物理速度节点 |
| `CheckReset` | R 重置、低于 -800 厘米时恢复 | 按键判断和高度分支 |

默认 `RollAcceleration=70`、`MaxSpeed=900`、`LookSensitivity=0.5`。MaxSpeed 是停止继续施加驱动的水平速度阈值，不是把所有外力和下坡速度硬性截断。当前只做键鼠基础，没有手柄、改键、暂停菜单或正式通关规则。
